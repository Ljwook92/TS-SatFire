# 산불 확산 예측의 누수 점검과 식생지수 변화량 실험

## 기존 결과의 해석

공식 사건 ID는 훈련 124개, 검증 13개, 시험 24개로 분리된다. 실제 파일 날짜와 TS별 8,236개 창을 대조하여 모든 입력이 목표 파일보다 앞서는 것을 확인했다. 앞선 두 분할의 자료는 2017–2020년, 시험 자료는 2021년이다. TS=2/4/6 시험 창 중 전체 입력–정답 구간에 달력 공백이 있는 창은 각각 14/28/42개이며, 마지막 입력 바로 다음 달력 날짜가 정답이 아닌 창은 각 7개이다. 기본 실험은 다음 관측 파일을 예측한다.

같은 날짜의 256×256 격자를 좌표로 비교하면 다음 훈련·검증 쌍이 겹친다. 비율의 분모는 두 crop 중 작은 쪽의 면적이다. 겹친 621,264 픽셀·일에서 I1 값이 일치했다(같은 위치의 결측 쌍 포함). 아래의 공통 TS2 정답일에는 양쪽 모두 신규 화재 양성인 동일 위치가 없었다. 배경과 경계 조건을 공유하므로 검증 성능의 독립성이 제한된다. 점수가 얼마나 달라졌는지는 이 검사로 계량할 수 없다.

| 훈련 | 검증 | 같은 날짜 | 공간 중첩 | 공통 TS2 정답일 |
|---|---|---:|---:|---:|
| 22712973 | 22712904 | 16 | 50.15% | 14 |
| 24462488 | 24462610 | 26 | 4.21% | 24 |
| 24461320 | 24462610 | 16 | 2.26% | 14 |

같은 날짜·공간에서 훈련/검증과 시험이 겹친 사건 쌍은 0개, 시험 내부에는 9쌍 있었다. 같은 시험 사건들을 개발 도중 여러 번 열람하여 구조를 수정했으므로 0.391685는 반복 탐색한 벤치마크의 사건별 평균이다. 최종 성능 확인에는 별도 미열람 사건 또는 연도가 필요하다. 사건별 평균은 정답·예측이 모두 비면 1점을 주므로 신규 픽셀이 있는 날의 IoU와 pooled IoU도 함께 보고한다.

기존 Transformer 정규화는 훈련 사건 입력 2,130 event-days로 계산했다. 배포된 정규화 파일과 TS별 가중치는 원래 학습 실행 파일과 바이트 단위로 일치한다. 경계 CNN의 epoch/임계값은 검증 pooled IoU로 정한다. 뉴멕시코 6월 1일의 정답 102개를 서로 겹치지 않는 위치로 바꾸고 정답 파일에서 영상 필드를 제거한 개입 검사에서, 세 TS 모두 입력 영상·경계 특징·기본 점수·방위 영역·방위 비율이 같았다. 과거 누적 열영상·누적 화재 지도에는 입력 창 시작 전의 과거가 포함된다.

방위 회귀는 훈련 목표 분포로 계수를 적합하고 검증 자료로 규제 강도를 골랐다. 학습 코호트 구성은 실제 확산이 있고 방향을 판정할 수 있는 날에 조건을 걸었다(선택 편향). 실제 추론용 공개 번들의 488개 입력일 분포는 저장된 계수와 입력일 특징만으로 재계산해 최대 절대차 1e-15 미만을 확인했다. 날짜 연속성 검사에는 목표 관측일 일정이 쓰인다. 미래의 파일 도착 여부까지 알려져 있는 후향 실험이라는 점이 운영 예보와 다르다.

FirePred의 NDVI_last와 EVI2_last는 합성 제품이므로 TIFF 이름만으로 각 픽셀의 관측일/발행일을 복원할 수 없다. 공식 VNP13A1 설명은 16일 관측 중 대표 픽셀을 택하며 8일 간격으로 제공한다고 설명한다. 제품의 관측일·이용 가능 시각, 기상 예보의 발행 시각, 화재 라벨의 실시간 가용성을 전수 검증하지 않았다. 따라서 코드 수준의 과거 파일 규칙은 운영 시각 기준 무누수를 보장하지 않는다. [VIIRS VNP13A1 제품 설명](https://developers.google.com/earth-engine/datasets/catalog/NASA_VIIRS_002_VNP13A1)

## 검증 전용 Transformer 실험

기존 47채널에는 정규화한 NDVI/EVI2 수준이 있다. 기존 경계 CNN도 각 날짜의 수준을 받으며, 기존 8방위 모델은 방위 요약 ΔNDVI/ΔEVI2를 사용했다. 이번에는 Transformer의 패치 투영과 마지막 영상의 공간 입력에 픽셀별 변화량을 직접 제공한다. 입력 창 안의 연속 관측에서만 원래 FirePred 값을 정렬 후 1/10000 스케일로 환산해 차분한다. 첫 입력, 날짜 공백, 비유효 값의 변화량은 0이며 별도 유효성 채널로 실제 무변화와 구별한다. 원제품 QA가 들어 있지 않아 유한값 판정으로 구름을 걸러내지는 못한다.

훈련 124개를 유지하고 시공간 중첩이 있는 검증 ID 두 개를 제외한 11개 사건을 사용한다. 세 모델은 같은 무작위 초기화·데이터 순서·4 epoch·AdamW(lr 0.0003)·51채널·유효성 마스크를 사용한다. levels는 두 변화량 채널을 0으로 고정하고, ndvi는 ΔNDVI, both는 ΔNDVI와 ΔEVI2를 활성화한다. 전체 Transformer를 처음부터 학습한다. 경계 CNN과 방향 보정 전 직접 예측의 검증 IoU로 입력 변화량의 효과를 비교한다. 기존 시험 24개는 사용하지 않는다. 검증 자료의 양은 TS 2/4/6 각각 213/191/169개 창이다. TS 간 직접 비교에는 공통 날짜가 별도로 필요하다. 이 실험도 운영 시각을 검증하지 않은 FirePred를 사용하는 후향 비교이다.

기존 캐시를 사용해 할당된 HPC GPU 터미널에서 실행한다. 매번 새 출력 폴더를 만들고 전체 결과는 그 안의 TS별 validation_choices.csv에 기록한다. 추가 시드는 SATFIRE_SEED 환경변수로 지정한다.

```bash
cd /home/jlc3q/data/SatFire/TS-SatFire
git pull --ff-only origin main
cd experiments/boundary_gpu
bash run_delta_ablation.sh /home/jlc3q/data/SatFire/boundary_runs/run-20261124-150401-KMbDKD/cache
```

로컬 검사는 train 124개와 선별된 val 11개의 모든 인접 입력일 식생지수 전처리를 포함한다. 훈련 입력일 쌍 2,006개 중 258쌍에서 ΔNDVI가 변한 픽셀이 하나 이상 있었다(변화 기준 절대값 > 0.00001). 전체 유효 픽셀쌍 중 변화 비율은 NDVI 9.4377%, EVI2 9.4368%였다. 세 창 × 세 입력 조건으로 CPU에서 1회 훈련 단계와 검증 경로를 확인했다. 전체 GPU 학습의 성능 결과는 사용자 HPC 실행 후 산출된다.
